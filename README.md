# 반야심경

수지독송을 위한 현대 한국어 《반야심경》 번역입니다. 현장 한역을 기준으로 읽고, 산스크리트 전승과의 차이는 번역 주와 근거 기록에 구별합니다.

> 현재 번역·교정 중인 초안입니다. 표현과 주석은 검토에 따라 달라질 수 있습니다.

## 읽기

처음에는 **[한글 번역을 이어 읽기](reader/korean.md)**로 시작할 수 있습니다.

- **[구절별 대조](reader/parallel.md)**: 한 구절씩 한글 → 한문 → 현토를 읽고 관련 번역 주와 용어로 이동합니다.
- **[번역 주](reader/notes.md)**: 문법·해석·판본 차이를 살피고 해당 본문으로 돌아갑니다.
- **[용어 대응](reader/terms.md)**: 한역 용어와 이 번역의 표현을 찾고, 산스크리트 대조 어구와 선택 이유를 확인합니다.
- **[한 문서로 모두 읽기](translation/01-heart-sutra.md)**: 기존의 한글 번역 → 번역 주 → 한문·현토 구성을 보존한 문서입니다.

이어 읽기는 기존 11개 문단을 유지합니다. 구절별 대조의 16개 번호와 소제목은 읽기를 위한 편집상 안내입니다. 문서 사이의 링크로 본문·주석·용어를 오갈 수 있습니다.

## 기준본과 번역 원칙

한문 기준은 현장(玄奘) 역 《般若波羅蜜多心經》, 《大正新脩大藏經》 T08 No.251의 CBETA 교감 주본문입니다. 제목·역자·두 서문을 제외하고 진언을 포함한 경문 260자를 수록합니다.

원문의 표현과 문법에 충실하게 옮기며 본문에 해설을 덧붙이지 않습니다. 산스크리트 소본은 대조 자료로 사용하고, 한역과 다른 문구를 하나의 본문으로 합치지 않습니다. 현토 독음은 한문을 한국어로 읽는 독음입니다.
